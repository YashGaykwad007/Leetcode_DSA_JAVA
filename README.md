## How to use

- Each numbered folder follows the sheet's section order.
- Each numbered `.java` file is a placeholder; add your solution inside the class.
- File and folder numbers keep the sheet order visible in GitHub.
- Names and capitalization follow the source where practical. Some source labels are broad exercise names rather than canonical platform titles.
